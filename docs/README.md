# CW-Trainer Documentation

This folder helps new contributors understand how the app is organized and how to add features safely.

## Start Here

- [Architecture](./architecture.md): layers, data flow, and key decisions.
- [Project Structure](./project-structure.md): where to find features, hooks, store, and domain logic.
- [Contributing Guide](./contributing.md): local setup, quality checks, and PR expectations.
- [Feature Development Guide](./feature-development.md): step-by-step path for implementing new functionality.

## Quick Onboarding

1. Read [Architecture](./architecture.md).
2. Run the app and tests locally.
3. Pick a small feature and follow [Feature Development Guide](./feature-development.md).
4. Use [Contributing Guide](./contributing.md) before opening a PR.
